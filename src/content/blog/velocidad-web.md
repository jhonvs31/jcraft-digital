  <p>Tienes literalmente segundos para captar la atención de alguien que llega a tu sitio web. Si tu página tarda en cargar, ese visitante se va — y probablemente a la competencia. La velocidad de carga no es un detalle técnico: es un factor crítico de conversión.</p>

      <div class="speed-stats">
        <div class="stat-box"><div class="stat-num">≤ 2,5 s</div>
  <div class="stat-label">es el tiempo que Google considera «bueno» para que cargue el contenido principal (LCP)</div>
  </div>
        <div class="stat-box"><div class="stat-num">Móvil</div>
  <div class="stat-label">es donde más se nota la lentitud: prueba siempre tu web desde el celular</div>

      <h2>¿Por qué la velocidad afecta tanto?</h2>
      <p>La velocidad de carga afecta tres áreas críticas de tu negocio digital:</p>
      <ul>
        <li><strong>Experiencia de usuario:</strong> Un sitio lento frustra. La impaciencia digital es real — las personas no tienen tolerancia para esperar.</li>
        <li><strong>SEO:</strong> Google usa la velocidad como factor de posicionamiento. Un sitio lento baja en los resultados de búsqueda.</li>
        <li><strong>Conversiones:</strong> Cada segundo de demora se traduce en menos ventas, menos contactos, menos leads.</li>
      </ul>

      <div class="highlight-box"><p>⚡ Core Web Vitals: Google mide la velocidad y experiencia de tu web con métricas específicas llamadas Core Web Vitals. LCP (carga del contenido principal), FID (interactividad) y CLS (estabilidad visual). Puedes verificarlas gratis en pagespeed.web.dev</p>
  </div>

      <h2>¿Por qué los sitios web son lentos?</h2>
      <p>Las causas más comunes de un sitio web lento son:</p>
      <ul>
        <li>Imágenes sin optimizar (archivos de varios megas cuando podrían pesar kilobytes)</li>
        <li>Hosting de baja calidad o sobrecargado</li>
        <li>Demasiados plugins o scripts de terceros</li>
        <li>Código CSS y JavaScript sin minificar</li>
        <li>Sin caché configurada</li>
        <li>Sin CDN (red de distribución de contenido)</li>
        <li>Temas de WordPress pesados o mal codificados</li>
      </ul>

      <h2>Cómo mejorar la velocidad de tu sitio web</h2>

      <div class="fix-item">
        <div class="fix-icon">🖼️</div>
        <div class="fix-content">
          <h3>Optimiza las imágenes <span class="difficulty-badge easy">Fácil</span></h3>
          <p>Convierte tus imágenes al formato WebP (mucho más liviano que JPG o PNG) y comprimelas antes de subir al sitio. Herramientas gratis: Squoosh (squoosh.app) o TinyPNG. Una imagen que pesa 3MB puede reducirse a 150KB sin pérdida visible de calidad.</p>
        </div>
      </div>

      <div class="fix-item">
        <div class="fix-icon">🏠</div>
        <div class="fix-content">
          <h3>Mejora tu hosting <span class="difficulty-badge medium">Medio</span></h3>
          <p>Un hosting lento es el problema más limitante y el más difícil de compensar con otras optimizaciones. Si usas hosting compartido barato, considera migrar a uno de mejor calidad. En Colombia, opciones como Hostinger, SiteGround o DigitalOcean ofrecen buen rendimiento a precio razonable.</p>
        </div>
      </div>

      <div class="fix-item">
        <div class="fix-icon">⚡</div>
        <div class="fix-content">
          <h3>Activa la caché <span class="difficulty-badge easy">Fácil</span></h3>
          <p>La caché guarda una versión estática de tu web para que las visitas repetidas carguen mucho más rápido. En WordPress, plugins como WP Rocket o W3 Total Cache lo hacen automáticamente. En otros sistemas, configúralo desde el servidor o el CDN.</p>
        </div>
      </div>

      <div class="fix-item">
        <div class="fix-icon">🌐</div>
        <div class="fix-content">
          <h3>Usa un CDN <span class="difficulty-badge medium">Medio</span></h3>
          <p>Un CDN (Content Delivery Network) distribuye tu web en servidores alrededor del mundo, para que cada visitante cargue los archivos desde el servidor más cercano a su ubicación. Cloudflare ofrece una versión gratuita que marca una diferencia notable.</p>
        </div>
      </div>

      <div class="fix-item">
        <div class="fix-icon">🔧</div>
        <div class="fix-content">
          <h3>Minifica CSS y JavaScript <span class="difficulty-badge hard">Técnico</span></h3>
          <p>Minificar significa eliminar espacios, saltos de línea y comentarios del código para que los archivos sean más pequeños. En WordPress hay plugins que lo hacen automáticamente. En sitios personalizados, lo hace el desarrollador como parte del proceso de build.</p>
        </div>
      </div>

      <div class="fix-item">
        <div class="fix-icon">📱</div>
        <div class="fix-content">
          <h3>Lazy loading en imágenes <span class="difficulty-badge easy">Fácil</span></h3>
          <p>El lazy loading hace que las imágenes se carguen solo cuando el usuario llega a ellas al hacer scroll, en lugar de cargar todo el contenido al abrir la página. En HTML moderno basta con agregar el atributo loading="lazy" a tus imágenes.</p>
        </div>
      </div>

      <h2>¿Cómo medir la velocidad de tu web?</h2>
      <p>Antes de optimizar, mide. Estas herramientas gratuitas te dan un diagnóstico detallado:</p>
      <ul>
        <li><strong>Google PageSpeed Insights</strong> (pagespeed.web.dev): La herramienta oficial de Google. Da puntuación del 1 al 100 y recomendaciones específicas.</li>
        <li><strong>GTmetrix</strong> (gtmetrix.com): Análisis más detallado con cascada de carga y sugerencias técnicas.</li>
        <li><strong>WebPageTest</strong> (webpagetest.org): Para análisis avanzados desde diferentes ubicaciones del mundo.</li>
      </ul>

      <p>Un sitio web bien optimizado debe apuntar a más de 90 puntos en PageSpeed Insights en mobile y desktop, y a menos de 2.5 segundos de LCP.</p>
